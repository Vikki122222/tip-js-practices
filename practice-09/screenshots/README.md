# Скриншоты практической работы № 9

В этой папке находятся все 43 сохранённых скриншота выполнения ПР9.

Основные изображения вставлены в `../README.md`. Остальные снимки дополняют отчёт и подтверждают дополнительные проверки.

## Содержание

- Запуск API и успешные GET-запросы.
- Индивидуальный вариант №3 и комбинированная фильтрация.
- Проверки поиска, регистра и длины строки `q`.
- Проверки `completed`, `priority` и `categoryId`.
- Некорректные и повторяющиеся параметры.
- Ошибки `INVALID_QUERY`, `INVALID_ID`, `TASK_NOT_FOUND`, `ROUTE_NOT_FOUND`.
- Запрещённые методы, HEAD и OPTIONS.
- Перезапуск сервера и автоматические тесты.

90 — количество автоматических проверок (38 модульных + 52 HTTP), а не количество скриншотов.
